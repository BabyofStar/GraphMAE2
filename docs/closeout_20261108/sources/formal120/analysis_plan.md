## 固定指标与主要比较

- 目标方法固定为B2，主要比较固定为每个数据集内、同训练种子的B2与B0。
- 主指标固定为 `val_selected_test_acc`，即最终预训练编码器与验证集选中分类器的测试准确率；不与 `final_test_acc` 择优。
- 表格展示准确率百分比的均值和总体标准差，ddof=0，与项目历史口径一致。
- 配对差值为 `100 * (B2_score - B0_score)`，单位为百分点。分别报告10个差值、均值、样本标准差、胜/平/负次数。
- 每个数据集用双侧配对t检验及配对均值的95% Student-t置信区间，df=9；区间计算采用样本标准差ddof=1，不与表格的总体标准差混淆。
- 三个数据集的三项主要检验构成一个检验族，使用Holm校正，alpha=0.05。95%区间是各数据集的未校正区间，不是同时置信区间。
- 均值为正且主要检验校正后p<0.05，才称该数据集有统计支持的平均提升；仅均值为正时称观察到小幅改善，不能称证明有效。
- t检验与区间依赖训练种子间差值的独立性及均值分布近似等假设；结论条件于当前三个固定图、数据划分和实现，不代表对所有图或新测试节点总体的普遍结论。

## 统计实现依据

配对检验、df和均值差区间参见 [SciPy ttest_rel 官方说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_rel.html)；Holm多重比较校正参见 [statsmodels multipletests 官方说明](https://www.statsmodels.org/stable/generated/statsmodels.stats.multitest.multipletests.html)。

实际计算使用Python标准库，不需要在本地或服务器安装新依赖：df=9的t分布CDF采用换元 `t=3*tan(theta)` 后积分 `cos(theta)^8` 的闭式表达，分位数由二分求根获得；与配对t公式一致。计算代码通过8项单元测试，包括与独立密度数值积分比对、临界值核对、Holm排序、配对单位、课程调度及压缩包路径安全检查。此实现说明也在读取正式测试成绩前写入。
