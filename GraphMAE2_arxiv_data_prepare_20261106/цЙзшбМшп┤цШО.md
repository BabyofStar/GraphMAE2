## 执行

上传本压缩包到服务器项目目录，在JupyterLab终端运行：

```bash
cd /home/jovyan/work/GraphMAE2
unzip -n GraphMAE2_arxiv_data_prepare_20261106.zip
bash GraphMAE2_arxiv_data_prepare_20261106/run_prepare.sh
```

工具会在`/home/jovyan/work/GraphMAE2_artifacts/arxiv_prepare_XXXXXXXX`创建唯一目录：

1. 下载约79.2 MiB的官方OGB arxiv原始ZIP，保存来源、字节数与SHA256。
2. 检查ZIP路径、CRC和体积，写入该目录下`dataset/ogbn_arxiv`，核对原始节点/边数、特征维度样本及官方时间划分的范围、互斥和覆盖情况。
3. 从上游提供的官方分享入口寻找`ogbn-arxiv-lc-ego-graphs-256.pt`，找到则下载并记录身份。文件上限512 MiB；不改变256节点局部聚类定义来绕过下载问题。
4. 生成包含准备状态和必要页面元信息的`preparation_return.zip`，不把大数据或聚类文件再下载回本地。

**结束后回传终端`RETURN_FILE`对应的`preparation_return.zip`。**成功与部分完成都会保留结果；聚类位置未找到时也保留已经下载的数据，不触发新环境安装或训练。中途失败会输出具体原因和保留目录，不覆盖原有实验或权重。

本工具只使用Python标准库；不安装或升级依赖，不导入项目训练模块、不加载.pt/pickle、不启动GPU任务。官方聚类二进制的内部节点列表、顺序、根节点、范围与数据指纹需在接续工程阶段验证，下载成功不等于训练验收通过。
