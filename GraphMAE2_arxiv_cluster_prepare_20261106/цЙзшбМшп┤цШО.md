## 本包要做什么

1. 验证已有数据SHA256，复用数据，不重复下载arxiv。
2. 在新输出目录创建`--system-site-packages`虚拟环境，仅在该隔离环境准备LocalGraphClustering 0.6.1及所需绘图/数据依赖。基础graphmae2环境不安装新包、不升级；前后核对Torch/DGL/NumPy/SciPy/scikit-learn版本。
3. LocalGraphClustering wheel与必要时的同版本源码均按PyPI发布SHA256核对；优先使用wheel，只有原生库不兼容时才在隔离目录用现有C++工具构建，不安装系统编译器。
4. 沿用固定GraphMAE2源码的`acl`、1000次迭代、alpha=0.15、rho=1e−6、ego_size=256和官方划分顺序。节点列表生成省去没有写入最终文件的conductance计算；先在6节点小图和9个arxiv根节点上与原函数逐项比对节点列表，再检验256个固定输入样本在串行/2进程下完全一致。
5. 根据样本测量估计全量生成成本。**工程上限固定30分钟**，只限制本次CPU聚类生成，不代表课程截止时间或完整训练预算。估计可承受时生成全部169,343个根节点的聚类，保存SHA256与读回检查；估计超出则先保留测量结果。实际达到上限时保留部分节点列表并停止。

本步骤不构建模型、不训练分类器、不使用标签挑选样本，不读取任何实验测试成绩。自行生成的聚类不会冒充失效链接中作者文件的字节复刻，最终会报告生成版本和文件身份。源码主目录不改写，旧J55和历史结果保持原状。

## 执行

上传本ZIP到服务器项目目录，运行：

```bash
cd /home/jovyan/work/GraphMAE2
unzip -n GraphMAE2_arxiv_cluster_prepare_20261106.zip
bash GraphMAE2_arxiv_cluster_prepare_20261106/start.sh
```

它会后台执行，打印`LC_PREPARATION_DIR`、日志路径和`RETURN_FILE`。公共项目锁阻止与本项目其他队列同时执行；同一包的启动回执会防止误开第二次。查看进度可用：

```bash
tail -n 30 /终端给出的输出目录/run.log
```

完成后回传打印路径中的`clustering_return.zip`。无需把虚拟环境、原始数据或全量.pt聚类文件下载回本地。若依赖或原生库失败，会保留具体日志并停止，不升级原环境或自动改采样方法。
