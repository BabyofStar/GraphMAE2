# DS9 / C9 独立审计与机制分析

日期：2026-11-05。结论：**DS9、C9 的产物审计均为 PASS，先前日志复算结果得到确认；当前没有发现能解释负结果的配置、数据或源码版本错配。结果不意味着结构感知遮蔽已达到性能上限。**

本轮只读审计，没有训练、安装依赖、修改 GitHub 或读取测试成绩 JSON。分析以最终编码器的 `best_val_acc` 为准，不将开发验证结果与正式测试表混算。

## 3. DS 生效了，但生效的反馈未转为额外分类收益

DS 与 S 都从首轮开始满足相同四层配额。每层整段训练的累计掩码总量也相同；DS 改变的是层内哪些节点更常被抽中。

下表的 CV 为单节点累计观察次数标准差除以均值，乘 100 后展示。层内相关系数为“最终重构误差 EMA 与累计观察次数”的 Pearson 相关，先分四层计算，再对层与三训练种子取均值。这是训练反馈描述，没有 p 值，也不作因果推断。

| 数据集 | S 次数 CV % | DS 次数 CV % | S 层内相关 | DS 层内相关 | DS 高误差前10%节点次数/本层均值 |
| --- | ---: | ---: | ---: | ---: | ---: |
| cora | 2.223 | 4.998 | -0.012 | +0.822 | 1.073 |
| citeseer | 4.480 | 4.711 | -0.011 | +0.271 | 1.019 |
| pubmed | 0.746 | 2.297 | -0.007 | +0.884 | 1.027 |

高误差前10%按各次运行最终 EMA 在各层排序确定，只是事后描述。DS 的抽样本来就依赖历史误差，因此观察到正相关首先说明实现确实产生了误差导向选择；它不能独立证明误差是有用的学习信号。

DS 的最终平均误差 EMA 相对 S 较低，但验证均值仍较低：

| 数据集 | S 误差 EMA 均值 | DS 误差 EMA 均值 | 相对变化 | DS−S 验证 pp |
| --- | ---: | ---: | ---: | ---: |
| cora | 0.396462 | 0.393157 | -0.83% | -0.133 |
| citeseer | 0.780715 | 0.779552 | -0.15% | -0.067 |
| pubmed | 0.293377 | 0.277474 | -5.42% | -0.200 |

**可支持的判断：训练反馈的误差水平更低，不保证分类验证更高。** 误差 EMA 的观测节点、时刻和频率由各自采样器决定，不是统一固定掩码下的独立重构评测；因此也不能据此宣称 DS 在统一任务上的重构能力更好。三图的 SCE 指数不同，不跨图比较误差绝对值。

**尚不能支持的判断：**“DS 一定追逐噪声节点”“难点完全不值得学”或“降低误差导致分类变差”。现有产物缺少逐节点的可比较误差时间轨迹及统一独立评测，不能判定高误差节点是可学习难点还是持续噪声。

## 4. C 同时改变了顺序和 S 使用量

每图三个训练种子使用完全相同的固定路线。前20%轮次均为 uniform，最后20%均为 density，中间按预设概率路由。

| 数据集 | 总轮数 | S/density 轮数 | uniform 轮数 | S 使用占比 |
| --- | ---: | ---: | ---: | ---: |
| cora | 2000 | 987 | 1013 | 49.35% |
| citeseer | 500 | 240 | 260 | 48.00% |
| pubmed | 2000 | 1024 | 976 | 51.20% |

因此，C−S 比较的是整个方案，不能单独检验“课程顺序是否有效”。Citeseer 的局部回升也可能与减少 S 使用量、随机路径或其他训练动态有关，本批没有同使用量打乱顺序对照，不能挑选一种解释当结论。当前总体结果不支持继续搜索起止时间，也不证明所有课程策略无效。

## 5. 更多可见邻居不是现成的统一解释

下表是训练后20%**稀疏记录步**中，被遮蔽节点没有可见一/二跳上下文的比例，先按记录步取均值，再对三训练种子平均。二跳口径为唯一、去自环的 ≤2-hop 邻域；不是每轮都记录，Cora/PubMed 各5步，Citeseer 仅2步。

| 数据集 | S 二跳零可见 % | DS 二跳零可见 % | C 二跳零可见 % | S 一跳零可见 % | DS 一跳零可见 % |
| --- | ---: | ---: | ---: | ---: | ---: |
| cora | 3.619 | 4.515 | 3.693 | 17.834 | 19.325 |
| citeseer | 13.019 | 13.600 | 13.860 | 29.375 | 30.056 |
| pubmed | 13.256 | 12.657 | 13.225 | 72.417 | 66.436 |

- PubMed 的 DS 零可见比例低于 S，但验证均值仍低于 S；Citeseer 的 C 零可见比例高于 S，但验证均值反而高于 S。因此不能把这个指标当作直接提分目标。
- 这个比例的分母是各方法当轮被遮蔽的节点集合，集合不同，比例变化也包含抽中节点组成的变化，不能直接等同固定节点上下文的改善或恶化。
- Citeseer 的48个孤立节点，S/DS 的累计观察次数相对全图均值约为0.999/1.012，不支持“DS 极度重复遮蔽孤立节点”的说法。
- 原 R9 已核对 S/R 在相同组内位置映射下，累计观察次数逐位置完全相同。S−R 的差异不能解释成 S 仅仅把所有节点累计次数变得更均匀。

需要分开看“层配额波动”“单节点观察次数分布”“可见上下文”“下游分类”。它们不是同一指标，也没有从现有结果建立单调关系。

## 7. 对下一步的判断

1. 不用重跑 DS9/C9 来修复已发现的配置错误，因为本次没有发现这样的错误；工程通过也不等于性能改进。
2. 暂停 DS 的误差强度搜索与 C 的时间调度搜索。它们已经回答了各自有限方案的探索问题，不需要删去负结果或把局部收益包装成整体改进。
3. 可以继续研究输入遮蔽，但下一步首先应检验**评分信号是否对应值得学习的信息**，而不是继续叠加已有模块。一个明确不同的候选是“历史学习进展”而非“当前误差水平”，见同目录《下一轮假设与必要对照.md》。这是待证伪候选，不是已决定实施的新算法。
4. 若继续研究 C 的顺序机制，先补同 S 使用量的顺序对照；若研究新评分，则需要同权重分布的打乱评分对照。两类问题分别设计，不能同时改变后再解释归因。
5. 下一轮方法、诊断、比较与预算先冻结；本轮没有新增训练。小图固定划分的反复验证选择仍有适应风险，开发结果不能宣称独立确认。

审计代码与机器结果为 `analyze.py`、`audit.json`、`analysis_results.json`；原始证据白名单与逐文件哈希保存在工作目录的 `download_manifest.json`。计划写于读取新诊断前，原终端成绩此前已经看到，不称预注册。
