## 4. S确实固定了配额，但“更多可见邻居”的解释未获支持

S在每层内均匀抽样，单节点入选率约为k_g/n_g，与全局随机的K/N接近。差异主要来自整数配额和节点间联合抽样关系；它没有直接保护任何节点的可见邻居。

| 数据集 | B0各层掩码比例时间标准差均值，百分点 | S对应值 |
| --- | ---: | ---: |
| Cora | 1.732 | 0.000 |
| Citeseer | 1.233 | 0.000 |
| PubMed | 0.333 | 0.000 |

上表基于稀疏日志步，证明配额约束生效；不直接证明分类收益来自特征密度。所有36次运行最终都观察了全部节点，首次记录全覆盖均在step 100，不能据此声称实际达到全覆盖的精确轮次相同。S与B0累计节点观察次数的变异系数也几乎相同。

下面为训练后20%内已记录日志步的平均，再对三个种子等权平均。数值是被掩码节点中无任何可见一/二跳邻居的比例，单位%。不是全部训练轮的平均。

Citeseer有48个非自环度0节点。S对它们的累计采样次数约为全图均值的0.999倍，B0约1.002倍，未显示S明显过度选择孤立节点。包内没有标签、预测和原始特征，不能进一步断言类别不平衡、异配或噪声是退步原因。

## 5. D评分影响了采样，但重构难度不等于下游语义价值

| 数据集 | B0误差EMA与log(1+度数)相关 | D采样次数与自身最终误差相关 | D最低密度层平均次数 | D最高密度层平均次数 |
| --- | ---: | ---: | ---: | ---: |
| Cora | −0.513 | +0.871 | 1042.64 | 985.31 |
| Citeseer | −0.663 | +0.282 | 251.64 | 249.94 |
| PubMed | −0.602 | +0.891 | 1818.40 | 1793.61 |

度数与重构难度并非同一概念：当前呈负关联，D确实较偏向低度或较高误差节点，不能把结果归结为评分完全没有生效。最终误差与累计采样次数的关系受自适应反馈影响，不是独立因果证据。

按同种子B0的最终误差选出最难10%节点，D对这些节点的采样次数相对其全图均值约为：Cora 1.083倍、Citeseer 1.020倍、PubMed 1.028倍。Citeseer的改动尤其较弱，其D最终截断误差评分CV约0.087，低于Cora的0.304和PubMed的0.342。

D在PubMed的最终节点误差EMA均值约从B0的0.293变为0.277，但验证均值仍下降0.133个百分点。该训练统计不能直接代替下游质量；它是在不同掩码条件下收集的EMA，也不属于同分布的独立重构评估。不能据此断言D只学到了噪声。

## 7. 下一步建议

1. 保留S为局部有效候选，D作为未超过v1的消融结果；不把三数据集整体描述为显著提升。
2. 优先增加“固定随机分组＋同样四组配额”的对照。固定与训练种子独立的分组种子，保持组大小、掩码数、组内抽样、随机数消耗形式与训练预算和S一致。它用于区分特征密度本身与一般分层约束/随机路径变化的作用。一个固定随机分组仍不能代表所有分组。
3. DS可作为组件交互的探索，但不预设会更好；若执行，应同时比较DS与S、B2，保留所有数据集。调整优先级的依据是S的机制尚未被识别、D单独没有额外验证收益。
4. 选定方法和参数后，再扩大独立重复与数据场景。新训练种子只增加固定划分下的训练随机性证据；此前已查看原测试划分的v1结果，新方法的推广性仍应由未参与方案选择的数据集或预先固定的新划分补充。

当前没有启动新训练，也未修改服务器或本地候选模型源码。原始输入及所有不利结果完整保留。
