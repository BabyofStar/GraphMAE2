## 在服务器执行

将压缩包上传到`/home/jovyan/work/GraphMAE2`，在JupyterLab终端执行：

```bash
cd /home/jovyan/work/GraphMAE2
unzip -n GraphMAE2_arxiv_L0_20261106.zip
bash GraphMAE2_arxiv_L0_20261106/run_l0.sh
```

`unzip -n`保留已有同名文件。runner会激活既有graphmae2环境并设置此前验收的CUDA动态库路径，不升级环境。

结束时显示`L0_REPORT=/home/jovyan/work/GraphMAE2/outputs/arxiv_l0_XXXXXXXX/preflight.json`。回传这个JSON即可继续判断缺项及进入L1的准备成本。输出不包括Token、远程Git凭据、完整环境变量或进程完整命令行。

`COLLECTED_REVIEW_REQUIRED_NOT_A_TRAINING_READINESS_PASS`表示信息收集完成，仍需依据实际输出检查前置条件；不是训练放行结论。`df`共享容量不能当个人配额，nvidia-smi型号/容量不能替代Torch实际可见配额，旧批次complete也不能单独证明GPU当前空闲。
