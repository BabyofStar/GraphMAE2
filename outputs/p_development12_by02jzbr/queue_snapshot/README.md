## 本轮回答什么

上一轮 DS 确实强化了高误差节点的选择，但没有相对 S 的整体额外分类收益。本轮检验：在相同密度配额、课程强度和权重数值分布下，以历史误差下降的代理信号选择节点，是否比按误差水平选择更有用。

| 分支 | 层内选择 | 用途 |
| --- | --- | --- |
| S | 原有密度分层＋均匀抽样 | 同批次基准 |
| H | 按快误差EMA排名，误差高的权重高 | 匹配难度对照；不等同原DS原始误差权重 |
| P | 按正的快/慢EMA差排名 | 候选方法 |
| PS | 将本分支的P排名权重在每层内打乱 | 对照评分与节点对应关系 |

主比较 P−S，支持比较 P−H、P−PS。H−S和PS−S保留为辅助比较。全部12次结束后统一汇总，不能因为前几个结果不理想就删种子或换方法。

Cora 沿用本项目的工程首图，只进行单图有限探索，不能据此宣称跨数据集改进。学习进展用于课程选择已有研究，本轮不是原创性认定或该论文的完整复现：[Graves等，ICML 2017](https://proceedings.mlr.press/v70/graves17a.html)。

## 冻结的评分与权重

每个被遮蔽节点先完成本轮选样及重构，随后才更新两个不带梯度的误差EMA。误差口径沿用原SCE诊断，训练损失、编码器、解码器和教师更新不变。

```text
第一次观察：fast = slow = 当前误差
后续观察：fast = 0.9 * fast + 0.1 * 当前误差
          slow = 0.99 * slow + 0.01 * 当前误差
H分数 = fast
P/PS分数 = max(slow - fast, 0)
```

两个EMA按“该节点被观察的次数”推进，不是按每个全局epoch更新。这是带有抽样噪声和观测频率依赖的学习进展代理，不代表已证明的真实可学习性。没有观察时两个EMA均为0，不使用未来误差、标签或分类成绩。

H/P/PS 每层完整排序，低分排前、高分排后。同分按固定私有CPU随机优先级打破，种子2026110504；这个优先级在训练种子间相同，不使用节点标签。未观察或P分数为0的节点也参与完整排序，因此即使出现大量同分，权重形状仍保持一致，但同分部分的区别来自随机优先级；短程需报告这类退化风险。

若一层有 m 个节点，排序名次 r 从1到m，固定权重为：

```text
w(r) = (1-alpha)/m + alpha * 2*r/(m*(m+1))
alpha = 0.5 * clip((epoch/max(E-1,1)-0.2)/0.6, 0, 1)
```

这样 H/P/PS 在同一轮、同一层的权重数值多重集完全相同，不受原始分数幅值、零分数或各分支不同反馈轨迹影响，无需额外共享评分模型。PS每轮每层用私有CPU种子 `2026110505 + 4*epoch + layer` 重排本层权重，独立重放可核对。私有随机数不改训练全局CPU/CUDA随机状态。

alpha为0时沿用S的层内randperm；之后采用同样的无放回加权抽样。每轮始终遮蔽1354个节点，四层大小677，配额339/339/338/338。H的排序不再应用原DS的0.95截断：本轮研究的是匹配排名形状下的评分依据，原DS仅作历史背景。

相同权重形状控制了采样强度，但各分支仍拥有各自的在线反馈和训练历史；P−PS评价整个评分策略，不能声称完全隔离所有长期训练动态。固定同分优先级也只使用一种配置。

## 测量筛查与HOLD

P的100轮诊断，在选样前的step50/60/70/80/90/99检查：

- 每个快照至少99%的节点已被观察至少5次。
- 已满足5次观察节点中，正进展分数占比至少5%，分数标准差大于1e-8。
- 六个快照上，进展分数与观测间隔、与累计观察次数的Pearson相关绝对值平均，各自须小于0.8。

这些是预先固定的启发式退化筛查阈值，没有统计检验意义；通过不证明评分具有真实可学习性，也不保证分类提升。分数与误差水平的相关会记录，但不作为放行成绩。

不满足时写 `measurement_gate.json`、`measurement_hold_receipt.json`，状态为 `measurement_hold`，**不会启动12次训练**。保留记录，先分析测量问题；同一包重启不会反复诊断或绕过HOLD。不要删除回执或根据分类成绩放宽阈值。
