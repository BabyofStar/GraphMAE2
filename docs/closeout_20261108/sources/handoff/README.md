### 5.1 v1：结构评分与课程

以去自环后的入度作为结构代理，采用对数变换：

```text
q_i = (log(1 + degree_i) + 1e-8) / sum_j(log(1 + degree_j) + 1e-8)
w_i(t) = (1 - alpha(t)) / N + alpha(t) * q_i

progress = epoch / max(total_epochs - 1, 1)
alpha(t) = 0.5 * clip((progress - 0.2) / (0.8 - 0.2), 0, 1)
```

前20%均匀随机，中间60%线性增加引导，最后20%固定0.5。alpha是引导强度，不是总掩码率；无放回采样权重不等于精确边缘入选概率。度数是结构代理，不能直接称为真实重构难度。课程进度独立传递，不改变原forward的epoch/EMA语义。

B3使用私有CPU生成器一次置乱评分，固定`structure_shuffle_seed=20261025`，各训练种子共用这次置乱，不额外消耗训练全局随机流。B1/B2的平均引导强度不同，不能仅据两者差异证明调度顺序的独立因果作用。

### 5.2 D：历史重构误差课程

从已发生的被掩码节点重构中取得逐节点SCE误差，detach/no_grad后更新EMA；首次观察直接赋值，后续beta=0.9。未观察节点用已观察误差的中位数填充，按0.95分位截断上端，保持正数下限后与均匀项混合，沿用0.5/0.2/0.8课程。

统计只影响未来采样，不增加额外前向、不替换训练损失、不改变教师EMA。重构困难不等于对分类更有价值，须由下游结果检验。

### 5.3 S：局部特征密度分层

以原始特征与唯一一、二跳邻居的平均余弦相似度定义密度；邻域按无向处理，去自环和重复，孤立节点密度为0。同分按节点ID稳定排序，近等量划分为4层，以最大余数法分配固定掩码配额，层内均匀无放回采样。

分块大小为256，不构造完整N×N相似度矩阵；当前实现仅验收三个小图。S从首轮起使用配额，不带D式难度课程。固定配额约束的是联合抽样数量，不能直接等同于更多可见邻居、类别均衡或更均匀的单节点累计次数。

### 5.4 R：固定随机分组配额对照

R用于检查S的收益是否依赖真实密度信息，而非只由一般分组配额或随机路径变化产生。

- 每图用私有CPU `torch.Generator`一次生成节点排列，按S的实际4组大小切分；组内采样沿用S的API、调用数量、张量形状和配额规则。
- Cora/Citeseer/PubMed的分组种子分别固定为**2026110301 / 2026110302 / 2026110303**，同一图在训练种子0/1/2下使用相同分组。
- 分组准备不改变训练全局CPU/CUDA随机状态，不使用标签、不根据成绩寻找有利分组。
- 真实`density_layer`和`local_feature_density`保留；随机组另记`sampling_group`、组内节点顺序、种子和指纹，避免诊断含义混淆。
- 训练期随机API形式相同不表示消除了所有随机性；节点集合和训练轨迹仍可不同。一份固定随机分组不能代表所有分组。

### 5.5 C：渐进启用密度分层

C复用已有课程框架，在每轮选择“全局均匀随机”或“S真实密度配额”，不使用度数或误差加权。前20%轮次均匀随机，中间60%将选择S的概率线性从0增至1，最后20%使用S；每轮总掩码数仍固定K。

路线由私有CPU生成器一次产生，不改变训练全局CPU/CUDA随机状态。Cora/Citeseer/PubMed路线种子固定2026110501/2026110502/2026110503，同一图的三个训练种子共用路线，并保存完整路线及指纹。路线概率与度数引导alpha含义不同。

本轮用户选择只做9次探索，未运行同使用量、打乱顺序对照。C使用S的期望轮数约一半，因此C−S仅评价完整方案，不能把差值单独归因于课程顺序，也不将C表述为全新独立优化理论。

### 5.6 P12：匹配权重形状的学习进展代理

S保持层内均匀抽样。H/P/PS只在同一密度层内改变加权选择，沿用每轮总掩码数、层配额和0.5/0.2/0.8课程。

节点被观察后，逐节点误差快/慢EMA分别以0.9/0.99更新，首次观察直接赋当前误差。H分数为快EMA，P/PS分数为`max(慢EMA−快EMA, 0)`。统计在选样及重构之后更新，只影响未来采样；未观察节点初始化为0。

每层按完整排名映射到固定权重模板，若层大小为m、名次r从1到m：

```text
w(r) = (1-alpha)/m + alpha * 2*r/(m*(m+1))
```

H/P/PS每轮每层的权重数值多重集完全相同，控制权重强度和形状。同分使用固定私有随机优先级；PS用私有CPU生成器每轮每层打乱本分支权重。原始分数不同不改变权重模板，但各分支仍有不同的反馈与训练历史。

EMA按该节点被观察的次数推进，不是每个全局epoch推进；P只是含抽样噪声和观察频率依赖的进展代理，不能称为真实可学习性。H使用排名权重且不做原DS上端截断，因此H不等同原DS。

### 5.7 J12：相同理论边际下的联合掩码

J12改变同一轮中节点共同被遮蔽的关系，不再按误差或进展加权。四组沿用真实密度四层和固定配额；每层m个节点、配额q时，每个节点理论入选概率均为q/m。相同理论边际不要求有限训练中的累计次数逐节点相等。

- S：原S的层内均匀选择，额外记录配对诊断。
- NA：在层内原图非自环无向边中，按正特征余弦降序贪心配对；未匹配节点私有随机补齐。尽量一遮一留。
- NR：层内固定随机配对，使用与NA相同的错开规则，检验图/特征配对是否有额外作用。
- NC：使用与NA完全相同的配对，尽量共同遮蔽或共同保留，检验关联方向。

配对计划跨训练种子固定，不用标签或分类成绩。Cora每层677个节点，形成338对加一个单节点；单节点每轮以q/m概率入选，剩余配额在随机配对顺序和公平单端方向下分配，避免固定遮蔽或固定保留造成偏差。小规模精确有理数穷举检查验证理论边际；每轮总数及层配额保持精确。

每次保存`pair_plan.json`及覆盖全部预训练轮次的`joint_trace.npz`，用于独立重算每轮配额、配对关系和节点累计次数。输入结构筛查不使用下游成绩，通过也不保证分类收益。图/特征配对包含随机补齐，不能将所有NA配对都称为相邻相似节点。
